# Atelier Desktop

**Искусство и ИИ в одном локальном рабочем пространстве.** Atelier Desktop — предварительная версия для macOS. Она помогает пройти путь от художественной идеи и исследования до редактируемых файлов и проверяемых визуальных результатов. Основа проекта — [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) и [DSH Desktop](https://github.com/dataelement/dsh-desktop) под лицензией MIT. У Atelier собственные оформление, интерфейс, творческий пресет и отдельный профиль пользователя.

## Что входит в предварительную версию

- **Искусство и 3D:** новые сеансы по умолчанию используют *Atelier Creative Mode* со Skill для Blender и настройкой подключения `mcp-for-blender`. Blender и дополнение MCP устанавливаются отдельно.
- **Повседневные задачи:** кнопки для документов, анализа и визуализации данных, протоколов, отчётов и презентаций вставляют редактируемую подсказку в поле ввода. Задача не отправляется автоматически.
- **Проверяемые файлы:** 3D-процесс требует сохранить редактируемую сцену и проверить изображения с разных ракурсов. Упоминание имени файла в ответе само по себе не подтверждает создание или проверку результата.
- **Модели и инструменты:** поставщик модели настраивается в приложении. Каталог MCP-коннекторов содержит отобранные проекты для искусства и дизайна. После добавления коннектора в пресет Atelier откройте новый сеанс и проверьте доступность инструментов. Каталог сторонних плагинов в этой версии скрыт.
- **Локальная работа:** рабочие пространства, сеансы и настройки хранятся в профиле Atelier отдельно от DSH. Интерфейс поддерживает китайский, английский и французский языки. Встроенный режим PPT может создавать редактируемые PPTX.

Это **ранняя локальная версия**. У Atelier пока нет собственного канала подписанных выпусков или автоматического обновления. Репозиторий сохраняет часть кроссплатформенного кода исходного проекта, но текущие инструкции и проверки Atelier ориентированы на macOS. Выпуски DSH Desktop не являются выпусками Atelier. Приложение также не заменяет многопользовательский веб-сервис Atelier.

## Запуск на macOS

Используйте **Node.js 24** и выполните в корне репозитория:

```sh
npm ci
npm run dev
```

Затем настройте поставщика модели в разделе **Настройки → Модели**. Ключи, сеансы и плагины из других профилей DSH не импортируются. Для локальной неподписанной сборки под Apple Silicon:

```sh
npm run package:dev:mac:arm64
```

Артефакты появятся в `dist-dev/`. Это не установщик для официального распространения.

Для работы с Blender установите Blender и `uvx`, включите дополнение `mcp-for-blender==2.0.4` и запустите его службу на `127.0.0.1:9876`. Перед моделированием проверьте подключение MCP. Подробнее — в [руководстве по локальной версии и результатам](README-ATELIER.md).

## Разработка, данные и происхождение

Запустите `npm test`, `npm run typecheck` и `npm run build`, а затем проверьте затронутый сценарий в приложении. [Архитектура](docs/architecture.md), [руководство разработчика](docs/development.md) и [руководство по PPT](packages/ppt-runtime/README.md) описывают унаследованную основу и местами сохраняют название DSH.

Atelier запускает Harness локально и использует отдельный каталог пользовательских данных. Процесс интерфейса изолирован и работает в песочнице. Поставщики моделей и MCP-сервисы могут обращаться к файлам или передавать данные в соответствии со своими разрешениями; проверьте подключение перед работой с конфиденциальными материалами. Не публикуйте ключи и файлы клиентов в репозитории.

Код, заимствованный из DSH Desktop, распространяется по [лицензии MIT](LICENSE). У DeepSeek Harness и других компонентов остаются собственные лицензии и сопровождающие. Atelier — независимая адаптация, а не официальный выпуск DeepSeek или DSH Desktop.
